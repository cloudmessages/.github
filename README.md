# cloudmessages/.github

This repository provides organisation-wide community health files and contributor defaults for the CloudMessages initiative.

Current maturity: bootstrap content for an early public draft effort.

CloudMessages is complementary to CloudEvents. It aims to standardise message envelopes and semantics for commands, queries, and their responses while preserving implementation-defined business payloads.
